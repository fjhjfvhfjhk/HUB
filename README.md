# Мой хаб веб-проектов

Единый портал для всех моих веб-игр, экспериментов и Minecraft-скинов. Один репозиторий — один сайт, а проекты и скины лежат в отдельных папках и обновляются независимо.

## Структура

/
├── index.html          ← главная (хаб)
├── hub.css
├── hub.js
├── projects.json       ← манифест проектов
├── skins.json          ← манифест скинов
├── icon.svg
├── .nojekyll
├── skins/              ← PNG-файлы скинов (64×64)
│   └── bebrik118.png
└── projects/
├── lux-7/          ← файлы проекта ЛЮКС-7
├── arcanum/        ← index.html = бывший arcanum.html
└── orbis/          ← index.html = бывший Orbis.html

```

## Как это работает

- `index.html` — сам хаб.
- `projects.json` — список всех проектов (название, описание, теги, цвет, путь).
- `skins.json` — список скинов (название, файл, ссылки на ely.by, автор).
- Каждый проект — папка внутри `projects/`.
- Каждый скин — PNG в `skins/` (или внешний URL).
- Запуск проекта — модалка с `iframe`. Кнопка «Новая вкладка» открывает отдельно (важно для PWA вроде ЛЮКС-7).
- 3D-просмотр скина — `skinview3d` (CDN), рендерится в canvas.

## Как добавить новый проект

1. Создать папку `projects/твой-id/` и положить туда `index.html` и остальные файлы.
2. Открыть `projects.json` и добавить запись:

```json
{
  "id": "твой-id",
  "name": "Название",
  "desc": "Короткое описание — 1–2 строки.",
  "path": "projects/твой-id/",
  "icon": "🎮",
  "tags": ["arcade", "2d"],
  "accent": "#f97316",
  "added": "2026-11-03"
}
```

Поля:

| Поле ↕▾ | Что это ↕▾ |
|---|---|
| −`id` | Уникальный ID (латиница, без пробелов) |
| −`name` | Отображаемое название |
| −`desc` | Описание — показывается на карточке (2–3 строки, обрезается) |
| −`path` | Путь до папки проекта с завершающим слэшем |
| −`icon` | Emoji или готовый SVG (`<svg>…</svg>`) |
| −`tags` | Массив тегов, из них строится фильтр |
| −`accent` | HEX-цвет для подсветки карточки |
| −`added` | Дата добавления (`YYYY-MM-DD`) — для сортировки |
⚙

3. Запушить. Всё — карточка появится автоматически.

## Как обновить существующий проект

Заменить содержимое папки `projects/<id>/`. Файл `projects.json` менять не нужно — хаб делает HEAD-запрос и берёт свежую версию через `Last-Modified`, если файл на сервере обновился.

## Как добавить скин

1. Положить PNG-файл (64×64, classic — формат Steve) в папку `skins/`. Если скин HD (128×128) — тоже работает, `skinview3d` рендерит любой размер.
2. Открыть `skins.json` и добавить запись:

```
{
  "id": "my-skin",
  "name": "Мой скин",
  "file": "skins/my-skin.png",
  "description": "Необязательное описание",
  "skinLink": "https://ely.by/skins/BebriK118",
  "author": "BebriK118",
  "authorLink": "https://ely.by/profile/BebriK118"
}
```

Поля:

| Поле ↕▾ | Что это ↕▾ |
|---|---|
| −`id` | Уникальный ID (латиница, без пробелов) |
| −`name` | Отображаемое название |
| −`file` | Путь до PNG (локально `skins/xxx.png` или внешний `https://...`) |
| −`description` | Необязательное описание |
| −`skinLink` | Прямая ссылка на страницу скина на ely.by |
| −`author` | Никнейм автора |
| −`authorLink` | Ссылка на профиль автора на ely.by |
⚙

3. Запушить. Появится карточка с 3D-превью, кнопкой скачать и ссылками.

### Как взять скин с ely.by

- Заходишь на `https://ely.by/profile/{ник}` → раздел «Скины».
- Скачиваешь PNG → кладёшь в `skins/`.
- В `skins.json` прописываешь `file`, `skinLink` и `authorLink`.

**Можно не хранить PNG локально** — в поле `file` укажи прямой URL на PNG (`https://...`). Но тогда:

- Скачивание может не сработать из-за CORS (откроется в новой вкладке — сохрани через Ctrl+S).
- При недоступности внешнего сервера — 3D-превью не загрузится.

Локальные PNG в `skins/` — надёжнее.

## Локальная разработка

`fetch('projects.json')` работает только по HTTP, не через `file://`. Запусти локальный сервер:

```
python3 -m http.server 8000
```

Затем открой `http://localhost:8000/`.

## Деплой (GitHub Pages)

1. Запушить всё в репо.
2. Settings → Pages → Branch: `main`, Folder: `/ (root)`.
3. Через 30–60 секунд сайт доступен на `https://<юзер>.github.io/<репо>/`.

Файл `.nojekyll` уже включён — он нужен, чтобы GitHub Pages не игнорировал папки, начинающиеся с `_`, и корректно отдавал файлы как есть.

## Возможности хаба

- 🔍 Поиск по названию / описанию / тегам (для скинов — по названию)
- 🏷️ Фильтр по категориям (строится автоматически из `tags`)
- ★ Избранное (сохраняется в `localStorage`)
- 🕒 Недавние (последние 12 запущенных проектов)
- 🎨 Скины: 3D-превью, модалка с 3D-просмотром, скачивание PNG, ссылки на ely.by
- ⌨️ Горячие клавиши: `/` — фокус на поиск, `Esc` — закрыть модалку, `1–9` — запустить N-й проект
- 🔗 Прямые ссылки: `/#project=lux-7` открывает проект, `/#skin=bebrik118` — скин
- 📱 Полностью адаптивно

## Тонкости

- **PWA-установка** (в ЛЮКС-7) не сработает внутри `iframe` — для этого есть кнопка «Открыть в новой вкладке».
- **Service Worker** в `iframe` не регистрируется — открывай в новой вкладке, если нужен офлайн.
- **localStorage** общий на домен, но ключи у проектов разные (`lux7_*`, `arcanum_*`), так что они не мешают друг другу.
- **skinview3d** загружается с CDN (`cdn.jsdelivr.net`). Если браузер не поддерживает WebGL2 или CDN недоступен — скин показывается как 2D-пиксель-арт.
